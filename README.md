# Cryptic 翻译助手（Cryptic Translate Assistant）

> 跨国商务屏幕翻译工具 · 绿色免安装 · 离线授权 · Windows 10/11

⬇️ **下载**：右侧 [Releases](../../releases/latest) 页获取最新版 zip，解压双击 `Cryptic翻译助手\Cryptic翻译助手.exe` 即用（无需安装）。

## 功能一览

- 🫧 **屏幕区域翻译（原地浸染）**：快捷键框选屏幕区域 → 本地 OCR 识别 → 译文直接覆盖渲染在原位置，双击或 Esc 即销毁并自动归档
- 💬 **聊天翻译墙**：输入即翻译上墙，气泡式会话流，一键复制译文，历史可删除/清空
- ⌨️ **三连空格输入辅助**：在任意标准单行输入框快速连按三次空格，弹出翻译预览（含回译校验），Enter 原位回填译文、Esc 取消不改动原文；密码框、多行与自绘控件自动保护，绝不读取
- 📸 **截图工作台**：框选截图、标注箭头/方框、可选翻译，图片物理隔离归档
- 👻 **实时穿透翻译**：锁定屏幕区域持续翻译，鼠标穿透不挡操作
- 🔐 **设备绑定授权（一机一码）**：Ed25519 离线验签，硬件标识绑定本机

## 隐私与网络

- OCR（屏幕文字识别）在**本地**执行；
- 文本翻译需要联网，会将文本发送至所选第三方翻译服务（含免 Key 公共通道），受第三方服务条款、限额及可用性影响；
- 请勿翻译不应对外披露的敏感文本。
